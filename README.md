# TT-Aufstellung

Tool zur Optimierung einer Tischtennis-Mannschaftsaufstellung.

Der erste Projektschritt ist bewusst konzeptionell: Anforderungen, XTTV-Risiken, Gesamtarchitektur, Datenmodell, Importstrategie, Statistik-/ML-Ansatz, API, mobile-first Frontend und ein phasenweiser Entwicklungsplan sind in [`docs/architecture-plan.md`](docs/architecture-plan.md) dokumentiert.
